# 🧬 Glyph Core Logic — Sacred Quantum Builder Extension

This module contains the full **backend logic stack** for glyph generation, validation, and evolution — used live in the Nibiru11 build. These files represent the heart of the glyph system’s operational infrastructure, and serve as the functional bridge between `$aphira` language structures and `$phinx` logic compilation.

All files are written in TypeScript and were originally deployed in the `/frontend/utils/` directory of the Nibiru platform. They are now shared here as open-source extensions to the `$aphira` / `$phinx` tooling ecosystem.

---

## 📁 Contents

### `glyphLogic.ts`
> Primary routing layer. Handles glyph type dispatch, condition routing, tier logic delegation, and visual evolution checks.

### `glyphUtils.ts`
> General-purpose utility functions for glyph structure handling, string parsing, key normalization, and modular reference exports.

### `glyphPatterns.ts`
> Handles recognition and validation of glyph patterns — e.g., valid symmetry groups, recursive code shapes, or harmonic codes.

### `glyphValidation.ts`
> Tier enforcement, `SpiritZip` decoding, and rule-layer authorization logic. Ensures glyphs match defined validation trees.

### `glyphStandardization.ts`
> Type normalization and canonical glyph structure mapping. Used for transforming legacy glyphs or ensuring cross-engine compliance.

### `glyphEvolution.ts`
> Manages visual XP scaling, tier-based enhancements, and conditionally unlocked aesthetic glyph states (e.g., Aura unlocks).

### `glyphGenerator.ts`
> Procedural glyph constructor. Can create random or deterministic glyphs based on seed logic, user level, or symbolic intent.

### `glyphDataAccess.ts`
> Handles secure storage, permissioned lookup, and dynamic retrieval of stored glyph metadata for use in client systems.
